# Android　迷惑電話ブロッカー

このアプリは、Androidで使用することのできる、迷惑電話撃退アプリです。

## フリーダイヤル番号ブロック

0120、0800のフリーダイヤルをブロックします。

## 国際電話ブロック

国際電話のブロックができます。

## 完全無料・プライバシーの安全

これらの機能をすべて無料、追加料金なしでご利用いただけます。また、ストレージへのアクセスなども致しません。

## ブラックリスト・ホワイトリスト機能

登録しておくことで、常に許可する、常にブロックすることができます。

## 連絡先・通話履歴連携機能

連絡先の電話番号をブロックしない機能を追加しました。

また、通話履歴と連携しているので、履歴から直接ブロックすることもできます。
