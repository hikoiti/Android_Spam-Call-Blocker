======Japanese　日本語======

# セキュリティポリシー

本プログラム（迷惑電話ブロッカー）は、機能向上のために以下の権限を使用します。

* **連絡先へのアクセス**: 登録済みの安全な連絡先からの着信をブロック対象から除外するために使用します。
* **着信履歴へのアクセス**: 着信履歴から許可又はブロックができるようにするために必要です。

### データの取り扱いについて
取得した連絡先データおよび着信履歴は、**すべてユーザーの端末内（ローカル）でのみ処理されます。外部のサーバーへ送信・収集されることは一切ありません。**


万が一、本プログラムにおけるセキュリティ上の脆弱性やデータ漏洩の懸念を発見された場合は、公開の Issues には書き込まず、以下の窓口までプライベートにご連絡ください。

* **連絡先**: [hikoitisub-github.yahoo.co.jp]

報告受領後、速やかに確認と修正対応を行います。
また、セキュリティ面以外での不具合などがありましたら、Issuesにお書きください。


======English　英語======

# Security Policy

This program (spam call blocker) uses the following permissions to improve its functionality:

* **Access to Contacts**: Used to exclude incoming calls from registered, secure contacts from being blocked.

* **Access to Call History**: Necessary to allow or block calls from the call history.

### Regarding Data Handling
All acquired contact data and call history are **processed only on the user's device (locally).** They are never sent to or collected by external servers.

If you discover any security vulnerabilities or concerns about data leakage in this program, please do not post on public Issues, but contact us privately at the following address:

* **Contact**: [hikoitisub-github.yahoo.co.jp]

We will promptly review and correct the issue upon receiving your report.

For any other issues unrelated to security, please write them on Issues.
